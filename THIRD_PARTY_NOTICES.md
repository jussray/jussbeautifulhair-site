# Third-Party Components

Juss Beautiful Hair uses third-party software packages. Those packages remain
owned by their respective rights holders and are governed by their own license
terms.

## Dependency inventory

The repository's direct dependency declarations are recorded in:

- `package.json`
- `package-lock.json`

The lockfile also records transitive packages and package metadata used by the
installed dependency graph. Package versions, resolved archives, integrity
values, and license identifiers may change when dependencies are updated.

## First-party boundary

The root `LICENSE` applies to first-party source code, documentation, written
content, visual assets, and brand materials except where a file or component
states otherwise. It does not relicense third-party packages.

## Notice boundary

Third-party packages and components remain governed by their own licenses and
notices. This file is an attribution boundary and dependency-navigation aid. It
is not a representation that every transitive package's full license text or
every possible legal obligation has been reproduced here.

Before distributing a build or source bundle, review the exact dependency graph
for that release and preserve all notices and source-offer obligations required
by the applicable third-party licenses.

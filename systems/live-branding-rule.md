# Live-Branding Rule — canonical text

**Status:** Standing rule, ordered by Ray (founder) 2026-11-03. Applies portfolio-wide, accordingly per project.
**Canonical source:** this file, in the export-systems goal workspace. Repo copies under `systems/live-branding-rule.md` are exported artifacts — refreshed by PR, never edited in place as the source of truth.
**First implanted:** Founder Content System skill (`local-founder-content-system/SKILL.md`, channel-adaptation section) + the content-op posting-queue governance, 2026-11-03.

## The rule

> In any monetization post, EVERY content element — images, videos, reels, carousels, graphics, thumbnails — must carry the featured project's live site/app branding, accordingly per project. The live site/app is the source of truth for the look. Videos must match the same branded look as the project's approved stills. No generic templates, no unbranded media, no borrowed identity. Media that does not match the project's live branded look is MEDIA BLOCKED. This binds every social-media posting agent in the project and every AI agent working on it (Muse, Gemini, ChatGPT, Perplexity, Claude).
>
> **No-merge clause (added by Ray, 2026-11-03):** Never merge one app's view into another: each post carries only its featured app's live branded look; blended identities and cross-app look borrowing are prohibited.

## Enforcement notes

- The check happens at draft/approval time: media is compared against the project's **live** site/app branding (not a stale brand sheet, not a sibling project's identity).
- A post whose media fails the match is **MEDIA BLOCKED** — it does not publish until the media is rebuilt from the live branding and re-approved by the founder. Text approval never covers unseen media.
- Per-project look is whatever that project's live site/app shows today (e.g. Juss Beautiful Hair = LAWLESS purple-satin storefront identity). Each project keeps its own look; no cross-project borrowing. The Juss & Co house brand is its own view, not a blend of the portfolio's looks.

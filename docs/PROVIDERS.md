# Juss Beautiful Hair Provider Guide

Providers are replaceable capabilities. Product truth, customer trust, prices, payment state, and order consequences remain owned by the business.

## Claude / Claude Code

Best for repository analysis, storefront implementation, audits, and documentation. Must inspect real code and deployment settings rather than infer them from prior summaries.

## Codex / ChatGPT

Best for debugging, code review, tests, repository operations, data analysis, and founder-readable decisions. Tool evidence is required for claimed writes, checks, merges, or deployments.

## OpenAI Platform

Optional server-side AI capability behind a secure adapter. Never expose keys in the browser. Do not let model output create prices, product truth, customer promises, or order decisions without validation.

## Anthropic Platform

Optional server-side AI capability behind a secure adapter. Conversation context is not catalog or customer memory. Validate outputs before publishing or writing business data.

## Perplexity

Current public research, competitor scans, policy discovery, and source gathering. It does not know private supplier, customer, Stripe, Cloudflare, or inventory state unless explicitly connected and inspected.

## GitHub

Source, review, CI evidence, and rollback. A commit, PR, merge, Cloudflare build, deployed storefront, working payment link, and fulfilled order are separate states.

## Cloudflare

Static hosting and deployment. Verify the exact Pages or Workers target before changing configuration. Build success does not prove commerce behavior.

## Stripe

Payment boundary. Verify product, amount, currency, environment, link status, order-notification path, refunds, and customer support consequences before live changes.

## Required provider handoff

Every handoff should state the approved product facts, environment, customer impact, requested action, approval state, proof requirement, rollback, and sensitive data intentionally excluded.

No provider gets to improvise the price because the landing page looked emotionally persuasive.
